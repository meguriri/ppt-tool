# 页面样式与排版规范

## 尺寸与布局

- 设计尺寸固定 **1280×720**；根 html 的 iframe 就是 1280×720，页面不要自己做缩放。
- 页面内边距：左右 60–80px，上下 30–50px；内容区高度控制在 **~620px 以内**。
- `body { overflow: hidden }`，禁止出现横向滚动。
- 布局：标题在上、内容在下；左右分栏用 flex/grid，总宽度不超 1140px。

## 封面页（第 1 页）

- 白底黑字，只放标题（h1，≤ 56px），最多一行副标题（≤ 24px，灰色）。
- 用 `.cover` 类、内容居中；**不要**放标签、日期、图表、版本号等多余元素。

## 内部页布局

- 标题固定在上方：`.page-title`，距顶 40–60px，字号 28–40px，加粗，标题下方留 16–28px。
- 内容区：`.page-content`，`flex: 1`，字号 16–22px（演示大屏 20–24px），行高 1.5–1.8；
  内容底部距底 ≥ 20px。
- 简洁原则：默认无背景块、无边框卡片；需要强调时才用 1 种浅色块。

## 章节分页（标题不变、内容变化）

- 一个章节超过一页时，每页顶部用 `.chapter-header`：
  - 左侧 `.chapter-title`：章节标题文本在每页**完全一致**；
  - 右侧 `.chapter-page`：章节内页码 "k / n"，由写页 agent 标注。
- 只有 `.page-content` 的内容随页变化；根 html 底部圆点仍是整份演示的总页码。

## 皮肤（整体样式）

- 每页 `<link rel="stylesheet" href="skin.css">`；`skin.css` 与页 html 同目录（演示根）。
- 页面只写语义类（`.cover`、`.page-title`、`.page-content`、`.chapter-header` 等），
  颜色/字体/间距全部由 `skin.css` 决定。
- 换皮肤：替换 `skin.css`，或把 link 改成 `skins/<名称>.css`，页面结构不用动。
- 默认皮肤见 `assets/skin.css`（白底黑字、简洁），新建演示时一并复制。

## 字号与行距

- 页标题 h1：28–40px（封面可 56px）
- 小节标题：15–18px，加粗
- 正文：16–22px；演示大屏建议 20–24px
- 表格/小注：12–14px；图内文字 ≥ 11px
- 行高：1.5–1.8；段间距 10–18px

## 内容量（防溢出）

- 正文一页 ≤ 5–6 段，每段 ≤ 3–4 行
- 要点（bullet）一页 ≤ 6–8 条
- 表格行数 ≤ 8，列数 ≤ 6；列多时压缩字号或合并列
- 公式单独成行，一页 ≤ 4–6 条核心公式；长公式拆行
- 写完自查：内容底部 < 700px（距底至少 20px）

## 颜色

- 默认白底黑字（#fff / #111）
- 强调色最多 2–3 种；可复用：浅蓝块 #eaf4fd、蓝字 #2f6fbf、红 #c0392b、黄 #ffd54a
- 不用大面积深色背景，除非用户指定

## 越界检查清单

- 标题/正文/表格/公式/交互控件全部在 720 高度内
- MathJax 长公式给容器 `overflow-x:auto`，或拆成两行
- 表格/长文本加 `word-break: break-word`，单元格 `white-space: normal`
- 交互 SVG 用 `viewBox` + `width:100%`，不要写死超过容器的高度
- 预览验证：浏览器打开该页检查底部无截断；导出 PDF 抽查每页
